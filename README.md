# 🎵 Song Chatbot Management System

A Java-based Song Chatbot integrated with Spotify Web API.

## 🚀 Features
- Search songs by artist name
- Fetch top tracks dynamically
- Spotify API authentication
- JSON response parsing

## 🛠 Tech Stack
- Java
- Spotify Web API
- REST API
- JSON Library

## 📂 Project Structure
song-chatbot-management/
│── SongChatbot.java
│── SpotifyAuthManual.java
│── lib/json-20240303.jar
│── README.md

▶️ How to Run
Compile:
javac -cp ".;lib/json-20240303.jar" SongChatbot.java
Run:
java -cp ".;lib/json-20240303.jar" SongChatbot
